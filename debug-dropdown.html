DropdownMenu Debug Test

🔍 Testing Instructions:

  1. Open the browser console (F12 → Console tab)
  2. Click on the dropdown to open it
  3. Hover over items to see hover states
  4. Click on items to see selection and active states
  5. Hover over submenu items (with > arrow) to open submenus
  6. Watch the console for debugging information

Test 1: Basic Dropdown

This dropdown has a default selected value and should show active state immediately.

Test 2: Dropdown with Submenus

This dropdown has nested submenus to test active states in complex structures.

🔍 Console Debug Information:

Look for these debug messages in the console:

  • 🎨 Main render: Shows the main component state
  • 🎨 Colors: Shows hover color values
  • 🎨 renderSubmenuItems: Shows submenu rendering state
  • 🖱️ handleListClick: Shows click handling
  • 🖱️ handleSubmenuClick: Shows submenu click handling
  • 🔍 useEffect: Shows when active items are updated

🐛 Expected Behavior:

  • Default Selection: Items with matching value should show active background
  • Hover: Items should show hover background when mouse is over them
  • Active: Selected items and open submenus should show active background
  • Consistent: Active states should appear immediately on first click
